# Visual Basic Compiler & Code Analyzer

A Java-based compiler and source code analyzer designed to perform **lexical, syntactic, and semantic analysis** of Visual Basic (`.vb`) source code.

The application analyzes a Visual Basic source file, identifies potential errors, and generates a `.log` file containing the analysis results.

---

## 📌 Overview

This project was developed as an academic project to explore the fundamental stages of compiler design and source code analysis.

The analyzer processes Visual Basic code through different analysis stages:

* 🔤 **Lexical Analysis** — Identifies and validates tokens.
* 🌳 **Syntactic Analysis** — Checks whether the source code follows the expected grammar.
* 🧠 **Semantic Analysis** — Detects semantic inconsistencies and errors.
* 📝 **Error Reporting** — Generates a `.log` file containing the analysis results.

---

## ✨ Features

* Analyze Visual Basic (`.vb`) source code.
* Perform lexical, syntactic, and semantic analysis.
* Detect and report source code errors.
* Generate a `.log` file with the analysis results.
* Run directly from a `.jar` file.
* No specific installation directory is required.

## 📋 Requirements

Before running the application, make sure you have:

* **Java Runtime Environment (JRE)** or **JDK** installed.
* A Visual Basic source file with the `.vb` extension.
* The compiled `.jar` file generated by the project.

You can verify that Java is installed by running:

```bash
java -version
```

---

## 🚀 How to Run

### 1. Download or clone the repository

Clone the repository using Git:

```bash
git clone <YOUR_REPOSITORY_URL>
```

Or download the project as a ZIP file and extract it.

---

### 2. Prepare the files

Place the following files in the **same directory**:

```text
analizador/
├── compiler.jar
└── program.vb
```

> The `.jar` file and the `.vb` file must be located in the same directory.

The project does not require a specific installation path.

---

### 3. Open the terminal

Open **Command Prompt (CMD)** or another terminal.

Navigate to the directory containing the `.jar` and `.vb` files:

```bash
cd path/to/analizador
```

For example:

```bash
cd Desktop/analizador
```

---

### 4. Run the analyzer

Execute the following command:

```bash
java -jar compiler.jar
```

Replace `compiler.jar` with the actual name of your `.jar` file.

---

### 5. Enter the source file

After starting the application, the console will ask for the name of the file to analyze.

Enter the complete filename, including the `.vb` extension:

```text
program.vb
```

> The analyzer currently supports **Visual Basic source files (`.vb`) only**.

---

## 📄 Output

After the analysis is completed, the application generates a `.log` file in the same directory containing the input files.

Example:

```text
analizador/
├── compiler.jar
├── program.vb
└── program.log
```

The `.log` file contains the results of the analysis.

### If errors are found

The log file will contain the errors detected during the lexical, syntactic, or semantic analysis.

### If no errors are found

The `.log` file will not report errors and will contain the analyzed source code/results according to the application's output format.
